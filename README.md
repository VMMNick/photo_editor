# Фоторедактор (Android · Kotlin · Jetpack Compose · OpenGL ES 3)

Нативний Android-фоторедактор: вся кольорова обробка йде на GPU одним шейдером, ретуш і AI-ластик працюють на пристрої без мережі.

## Можливості

| Розділ | Що вміє |
|---|---|
| **Кадр** | Обрізка з пропорціями: вільна, оригінал, 1:1, 4:5 (Instagram), 9:16 (Stories), 16:9, 3:2, друк 10×15 / 13×18, A4. Поворот на 90°, віддзеркалення, вирівнювання горизонту (±45°) з автомасштабом без порожніх кутів, перспектива по вертикалі й горизонталі. Корекція об'єктива: дисторсія («бочка» / «подушка» без порожніх країв), хроматична аберація, віньєтування |
| **Світло** | Експозиція (±4 EV, у лінійному світлі), контраст, яскравість, світлі ділянки, тіні, білі, чорні. Тонові криві RGB і окремо R / G / B. Гістограма з індикаторами й підсвічуванням пересвіту та провалів. JPEG / PNG / WebP / HEIC та RAW |
| **Деталі** | Чіткість (локальний контраст), прибирання / додавання димки, різкість з порогом (не підсилює шум), шумозаглушення яскравісне (білатеральне) і кольорове. Радіуси прив'язані до розміру кадру — прев'ю і експорт у повній роздільності виглядають однаково |
| **Колір** | Температура і відтінок (баланс білого), насиченість, соковитість (vibrance), HSL для 8 діапазонів (відтінок / насиченість / яскравість), тонування тіней / середніх / світлих з балансом і змішуванням |
| **Ретуш** | Точковий коректор (сам шукає донорську ділянку й вирівнює тон), штамп з вибором джерела, AI-ластик: тап по людині чи предмету, і AI виділяє його (ML Kit Subject Segmentation), або обведіть пальцем. Заповнення — багатомасштабний PatchMatch |
| **Маски** | До 4 локальних масок: градієнт (небо), радіальна (обличчя), пензель, AI-об'єкт, AI-фон. Уточнення діапазоном яскравості або відтінку (наприклад, лише світле небо в градієнті чи лише зелень). У кожній: експозиція, контраст, світлі, тіні, насиченість, температура, відтінок. Інверсія, підсвічування маски |
| **Фільтри** | 19 вбудованих пресетів (Кіно, Вінтаж, Ч/Б, Настрій) з живими мініатюрами, повзунок інтенсивності, власні пресети. Імпорт 3D LUT (.cube з Lightroom / Resolve / Photoshop, до 65³) з інтенсивністю. Ефекти: віньєтка, зерно, вицвітання |
| **Пакетна обробка** | Копіювання налаштувань (світло, колір, деталі, криві, фільтр, LUT) і вставка в інше фото; «Застосувати до інших фото…» — до 50 фото експортуються з цими налаштуваннями по черзі |
| **Загальне** | Undo/redo (80 кроків, останні 30 переживають перезапуск), порівняння: шторка «до/після» (торкніться кнопки) або оригінал (утримуйте), незавершені редагування в «Продовжити редагування» на головному екрані (до 8, з мініатюрами й історією), масштаб двома пальцями, експорт у галерею (JPEG / PNG / WebP, розмір від 1080 px до оригіналу) |

## Збірка

1. Android Studio Ladybug (2024.2) або новіша. Gradle 8.11 запускається на JDK 17–21 (JBR з Android Studio 2025+ — це JDK 25, тому в `Settings → Gradle → Gradle JDK` оберіть 21).
2. `File → Open` → ця папка. Gradle сам завантажить залежності (AGP 8.7, Kotlin 2.0.21, Compose BOM 2024.12).
3. Запустіть на пристрої з Android 8.0+ (потрібен OpenGL ES 3.0). Для AI-функцій потрібні Google Play Services: модель сегментації (кілька МБ) завантажується при першому використанні.

З командного рядка: `./gradlew assembleDebug` (APK з'явиться в `app/build/outputs/apk/debug/`), тести ядра: `./gradlew test`.

## Архітектура

```
app/src/main/java/com/photoeditor/app/
├── model/     EditState (незмінний стан), пресети, збереження власних пресетів
├── core/      Чистий Kotlin без android.*: геометрія (гомографія), ретуш, PatchMatch-заповнення, растеризація масок
├── gl/        GLSL-шейдер, рендерер прев'ю (GLSurfaceView), офскрін-EGL для експорту й мініатюр
├── image/     Завантаження (EXIF, RAW), експорт у MediaStore, ML Kit сегментація
└── ui/        Compose: головний екран, редактор, панелі інструментів, жести й оверлеї
```

- **Недеструктивність.** Уся правка зберігається як `EditState`: параметри, геометрія, маски та список операцій ретушу в нормалізованих координатах. Прев'ю (≈2048 px) і експорт у повній роздільності відтворюють той самий стан, тому результат збігається.
- **Один прохід GPU.** Шейдер отримує матрицю «вихідний піксель → піксель джерела» (поворот, віддзеркалення, вирівнювання, перспектива, обрізка) і послідовно застосовує баланс білого та експозицію в лінійному світлі, тонові криві, HSL, маски, тонування, віньєтку й зерно.
- **Фільтр як дельта.** Пресет додається поверх ручних налаштувань з інтенсивністю 0..1, тому не затирає ваші корекції.
- **Експорт смугами.** Офскрін-рендер малює результат смугами по 512 рядків, щоб пам'ять не тримала два повнорозмірні буфери одночасно (до 24 Мп).

## Обмеження, про які варто знати

- **RAW.** DNG декодує сама система (Skia). Для CR2 / CR3 / NEF / ARW / ORF / RW2 / RAF Android не має декодера, тому застосунок бере вбудоване повнорозмірне JPEG-прев'ю камери і показує про це повідомлення. Обробка 8-бітна. Для справжньої 16-бітної RAW-проявки потрібна нативна LibRaw (JNI).
- **AI-ластик.** Виділення робить нейромережа ML Kit, а заповнення — алгоритм PatchMatch (content-aware fill, як «Заливка з урахуванням вмісту» у Photoshop). На однорідному чи повторюваному фоні він працює добре, на складних сценах генеративна модель (наприклад, LaMa через ONNX Runtime) дала б кращий результат: інтерфейс `Retouch.apply` дозволяє її підключити.
- Максимум 4 маски одночасно (обмеження кількості текстур у шейдері).

## Швидкодія

`PerformanceTest` міряє ключові операції на 12-Мп фото (4000×3000). Емулятор Android 17 з апаратним GPU на ноутбуці (i7-8750H):

| Операція | Час |
|---|---|
| Відкриття в редакторі (копія + декодування + підготовка) | 0,3–2,5 с |
| Декодування прев'ю 2048 px | 0,2–1,3 с |
| Рендер у повній роздільності з деталізацією (експорт) | 0,6–3,6 с |
| 19 мініатюр фільтрів | 0,15–0,2 с (спільний рендерер; до оптимізації — до 4 с) |

Менше число — вільний комп'ютер, більше — коли паралельно працює Android Studio з Gradle. На телефоні числа залежать від GPU; тест ловить регресії в рази.

Release-збірка з R8: APK ≈ 1,8 МБ (без моделі ML Kit, яку підвантажують Play Services).

## Випуск у Google Play

1. Створіть ключ: `keytool -genkeypair -v -keystore release.jks -alias photoeditor -keyalg RSA -keysize 4096 -validity 10000`.
2. Поруч із `settings.gradle.kts` створіть `keystore.properties` (він у `.gitignore`):
   ```
   storeFile=release.jks
   storePassword=…
   keyAlias=photoeditor
   keyPassword=…
   ```
3. `./gradlew bundleRelease` → `app/build/outputs/bundle/release/app-release.aab`. Без `keystore.properties` release підписується debug-ключем — для перевірки R8-збірки.
4. Політика конфіденційності — `docs/PRIVACY.md` (вкажіть контакт і опублікуйте за публічним посиланням; у Play Console в розділі «Безпека даних» — «дані не збираються»).

## Збереження роботи

Незавершене редагування не губиться, навіть якщо Android закрив застосунок у фоні.

- **Робоча копія.** При відкритті оригінал копіюється в `filesDir/session/`. Так фото можна перевідкрити після перезапуску процесу, навіть коли тимчасовий дозвіл на файл із галереї вже зник. З цієї ж копії робиться експорт.
- **Стан на диску.** Параметри пишуться в `state.json` через 0,6 с після останньої зміни та одразу при згортанні (`onStop`). Растрові маски (пензель, AI-об'єкт, області ластика) лежать окремими стиснутими файлами; незмінена маска повторно не пишеться.
- **Відновлення.** При холодному старті без нового фото сесія відновлюється автоматично, разом з останніми 30 кроками історії undo/redo (спільні растрові карти пишуться один раз).
- **Атомарність.** Імена файлів карт записуються в `state.json`, тож стан і перелік карт оновлюються одним атомарним записом.
- **Закриття фото кнопкою «Назад»** видаляє сесію.

Формат описано в `core/SessionCodec.kt` (версіонований JSON без сторонніх бібліотек, `core/MiniJson.kt`).

## Різкість при збільшенні

Прев'ю має до 2048 px, тож на великому збільшенні воно розмивається. Коли один піксель прев'ю займає більше ніж 1,15 пікселя екрана, а оригінал помітно більший, застосунок через 250 мс після зупинки жесту вирізає видиму ділянку оригіналу (`BitmapRegionDecoder`) і показує її поверх прев'ю.

- Враховується EXIF-орієнтація, поворот/віддзеркалення/перспектива кадру.
- **Коректор і штамп** застосовуються до тайла по-справжньому — ретуш на збільшенні теж різкий.
- **AI-ластик** на тайлі не запускається (це дорого); його області позначаються картою покриття, і там шейдер показує вже оброблене прев'ю.
- Для RAW тайли ріжуться з вбудованого JPEG-прев'ю. DNG, який декодує система, фрагментів не підтримує — там лишається звичайне прев'ю.

## Мови

Усі написи — у ресурсах: `values/strings.xml` (англійська, мова за замовчуванням) і `values-uk/strings.xml` (українська). На Android 13+ мову застосунку можна вибрати окремо від системної (`xml/locales_config.xml`). Модель (`model/`, `core/`) містить лише стабільні ключі; підписи для пресетів, пропорцій, масок і діапазонів HSL — у `ui/Labels.kt`. Щоб додати мову, скопіюйте `values-uk/strings.xml` у `values-<код>/` і додайте код у `locales_config.xml` та `resourceConfigurations`.

## Адаптивність

Інтерфейс підлаштовується під розмір вікна, а не під тип пристрою (`ui/AdaptiveLayout.kt`, брейкпоінти Material 3):

| Вікно | Розкладка |
|---|---|
| Телефон, портрет | фото зверху, панель налаштувань (≈36% висоти) і рядок інструментів знизу |
| Телефон боком, планшет у ландшафті, Chromebook (ширина ≥ 640 dp) | рейка інструментів ліворуч, фото по центру, панель праворуч (300–400 dp) |
| Планшет / розгорнутий фолд, портрет | як на телефоні, але панель вища (до 420 dp), щоб повзунки вміщались без прокрутки |
| Низький екран, split-screen | компактна верхня панель, фото завжди займає щонайменше 40% |

- Відступи беруться з `WindowInsets.safeDrawing`: статус-бар, навігація збоку в ландшафті, виріз камери.
- Поворот і зміна розміру вікна не перезапускають Activity (`configChanges`), тому GPU-контекст і стан редагування зберігаються; масштаб прев'ю при цьому скидається.
- На головному екрані на широких вікнах кнопки стоять поруч, а картки можливостей ідуть у 2–3 колонки.
- Діалог експорту прокручується, тож вміщається на телефоні боком.

### CI

`.github/workflows/android.yml` запускає unit-тести та збірку APK (вивантажується як артефакт) на кожен push, а інструментальні тести — на емуляторі API 34.

Локально всі тести проходять на емуляторі Android 17 (API 37): `./gradlew testDebugUnitTest connectedDebugAndroidTest`.

Шейдер додатково перевірено компіляцією та рендером у WebGL2 (GLSL ES 3.00) на тестових сценах.
